## Task DL-3 — Lexicon disposition classifier + entropy normalisation (commit c756aa29)

**Task:** f9wnnhvihgtkzfo | DL-1 ✅ DL-2 ✅ unblocked; full signal contract filled.

### What was built

**`disposition.py`** (new file)
- `LEXICON` dict: 6 dispositions × keyword sets — `concern` (danger/warning/alert/unsafe/risk…), `reluctant` (cannot/sorry/unable…), `uncertain` (maybe/unsure/perhaps…), `warm` (great/done/wonderful/glad…), `confident` (certain/yes/definitely/absolutely…), `curious` (why/how/interesting/explain…)
- `classify_disposition(tokens) → str`: weighted vote — each J-space token's weight (0..1) accumulates to its matched disposition; highest total wins; falls back to `"idle"` when no keyword matches
- BPE prefix normalisation: strip `▁`/`Ġ`/`ġ` **before** lowercasing (avoids Unicode fold bug where `Ġ` → `ġ` on `.lower()` and misses lstrip)
- Prefix match: `"certainly"` → `confident`; `"warning"` → `concern`

**`jlens.py`** additions
- `compute_raw_entropy(logits_np) → float`: raw softmax entropy in nats (pure numpy)
- `build_entropy_calibration(model, tokenizer)`: runs 25 CALIB_PROMPTS, collects per-position next-token raw entropies → `{"min": float, "max": float}` in nats
- `load_or_build_entropy_calibration()`: caches to `entropy_stats.json` (gitignored alongside `jlens_cache.npy`)
- `normalise_entropy(raw, stats) → float`: min-max scales to 0..1 using calibration bounds

**`server.py`** updates
- `entropy_stats` global; `load_model()` now also builds entropy calibration at startup
- `compute_step_entropy(logits, stats=None)`: optional `stats` param — with stats → calibrated min-max; without → log(vocab_size) fallback (preserves all existing tests)
- `/infer`: passes `entropy_stats` for calibrated entropy; calls `classify_disposition(concept_tokens)` to replace `"idle"` placeholder → fills full `{answer, disposition, tokens[], entropy}` contract
- `/health`: exposes `entropy_calibrated: bool`

**`test_server.py`**: +19 new tests across 4 new test classes — all 39 tests pass
