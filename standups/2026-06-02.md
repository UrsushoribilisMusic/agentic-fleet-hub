## Phase 3 — Task aivmddavbfawuzv
**SC: Video generation — captions not rendered in output video**

Root cause: On iOS 17+, `UIGraphicsImageRenderer.image{}` returns a Metal-backed
UIImage where `.cgImage` is nil. `CaptionLayer.render()` had `guard let cgImage =
uiImage.cgImage else { return nil }` — silently returned nil every frame, so no
caption was ever composited onto video frames.

Fix (commit 97ef05f, branch task/aivmddavbfawuzv):
- CaptionLayer.swift: replaced `CIImage(cgImage: uiImage.cgImage)` with
  `CIImage(image: uiImage)` — handles Metal-backed UIImages.
- CaptionRenderingTests.swift: added regression test
  `testCaptionLayerRendersVisibleContent` that samples a pixel in the text-panel
  area (CIImage y≈119, x≈540) and asserts alpha > 0.

Status: peer_review (PB task aivmddavbfawuzv)
