### What was done

Built and validated the checksum-gated extraction pipeline in `pipeline/extract.py`:
- Stack: yt-dlp → ffmpeg 16kHz WAV → Whisper (small.en / medium) → PySceneDetect → librosa (RMS, BPM, flatness ratio) → hook/cliff JPEG → PocketBase beat_grammar record
- Checksum gate: `sha256(episode_id + source_url)`, skips on existing non-error record

### Bugs found and fixed during testing

1. **seek past EOF (EN-CEO-010)**: PySceneDetect produces a single-frame trailing shot (0.067s) at stream end. `cliff_t = last_shot.start + 0.5` overshot `duration_s`. Fix: skip shots `< 0.5s` when choosing cliff anchor; clamp against `shot.end_s` too.

2. **Whisper can't find ffmpeg**: Claude Code's shell does not inherit `~/.zprofile`, so `/opt/homebrew/bin` is not in PATH. Whisper calls `ffmpeg` by name via subprocess. Fix: patch `os.environ["PATH"]` at script startup to include `/opt/homebrew/bin` and venv bin.

3. **PocketBase unique-constraint on re-run**: Error records from a previous failed attempt share the same checksum as the successful retry. `POST` fails with `validation_not_unique`. Fix: check for existing error record by checksum; if found, `PATCH` it in-place instead of creating a new record. (DELETE is admin-only on this PocketBase instance.)

4. **500 MB file-size cap too low**: Some ReelShort compilations (EP1-9, ~13 min) are 531 MB at best quality. Fix: raised cap to 1 GB.

### New tool: pipeline/fix_frames.py

Patches missing `hook_frame.jpg` / `cliffhanger_frame.jpg` for already-processed episodes without full re-download. Downloads at lowest quality, extracts the frame(s), PATCHes PocketBase in-place.
