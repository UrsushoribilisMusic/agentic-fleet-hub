## SM-355: Auto table of contents + stable heading anchors

Implemented Wikipedia-style article furniture in Sovereign Mind on branch `task/l2977vudyn6341x`, commit `8385fbe`.

- **wiki/toc.js**:
  - `cleanHeadingText()`: Strips bold, italic, code backticks, HTML tags, and resolves piped/simple wikilinks and markdown links to labels.
  - `slugifyHeading()`: Generates deterministic, URL-safe heading anchor slugs.
  - `extractHeadings()`: Hierarchically extracts headings (H2 section titles, H3/H4 markdown subheadings in section bodies) with deterministic numbering (`1`, `1.1`, `1.2`, `1.2.1`) and deduplicated IDs (`overview`, `overview-2`). Fenced code blocks are ignored.
  - `shouldShowToc()`: Enforces Wikipedia-style threshold (hides TOC when < 4 headings).
  - `renderTocHtml()`: Renders accessible, collapsible hierarchical `<nav class="wiki-toc">`.
  - `renderSectionBodyWithAnchors()`: Injects stable anchor IDs on markdown headings with `#` permalink hover affordances.
- **Reader view (`wikiPageHtml`)**:
  - Renders collapsible sidebar TOC when page has >= 4 headings, collapses/hides layout when < 4.
  - Stable heading anchors on all H2/H3/H4 headings with `#` permalink links.
  - Hash navigation listener on page load and `hashchange` to scroll smoothly to targeted anchors.
  - Mobile responsiveness: prevents sidebar from crowding mobile viewports.
- **Admin console editor preview (`previewHtml`)**:
  - Renders Wikipedia-style collapsible TOC box at top of preview when >= 4 headings.
  - Heading jump links scroll to section preview cards.
- **Routing & Deep Linking**:
  - Composes with SM-352 routing: `/wiki/:collection/:page#anchor` and `/wiki/:collection/page/:slug#anchor`.
