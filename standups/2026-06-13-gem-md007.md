  - **Cross-video Return Rate:** Implemented cross-video return rate logic `return_rate_next_ep`. If the next episode (e.g. `episode_n + 1`) is found in a playlist or matched by title pattern (like `Chapter {N+1}`) on the channel, it fetches views for that video and computes: `return_rate_next_ep = next_views / current_views` for each geo segment.
  - **Cohort Auto-detection:** Checks the traffic source report for `ADVERTISING` views. If any views were paid, it tags the cohort as `paid`; otherwise `organic`. Added `--cohort` CLI parameter for manual override.
  - **Geo Bucket Pre-segmentation:** Grouped country-level YouTube and TikTok views into `IAP_TIER` (US, UK/GB, CA, AU, DE, CH, AT) and `REST`, and aggregated metrics before inserting.
- **TikTok CSV Aggestion:** Aggregates exported TikTok Analytics country data by `geo_bucket` and computes averages.
